# 사주 계산 엔진 규칙

`backend/saju/` 는 이 앱의 정확성을 책임지는 핵심이다. 웹 기능 때문에 만세력 결과가 바뀌면 안 된다.

## 불변 기준값 (tests/test_saju_regression.py 로 고정)

| 입력 | 기대값 |
|---|---|
| 양력 2000-01-01 12:00 (KST, 경도 보정 없음) | 년 기묘 · 월 병자 · 일 무오 · 시 무오, 직전 절입 대설 1999-12-07 22:47, 다음 소한 2000-01-06 10:00 |
| 양력 1990-05-15 14:30, 경도 126.98 | 보정 시각 13:57, 년 경오 · 월 신사 · 일 경진 · 시 계미, 일주 공망 신유 |
| 양력 2004-02-21 10:12, 경도 126.98 (Figma 예시 명식) | 시 신사 · 일 경오 · 월 병인 · 년 갑신 |
| 1984년 (입춘 이후) | 갑자년 |
| 2000-01-01 일주 | 무오 (`(JDN + 49) % 60`) |
| 1950-06-15 10:00 | 일주 신사 (1970년 이전 날짜 — Windows 크래시 회귀 방지) |

## 계산 규칙 (임의로 바꾸지 말 것)

- 년주: 입춘(황경 315°) 기준. 월주: 12절 기준, 오호둔. 절입은 **절대 시각**(보정 전)으로 비교.
- 일주·시주: 경도 보정(평균태양시, 선택적으로 균시차) **후** 시각 기준.
- 자시 23:00 시작. `split_zi=False`(기본)는 23시부터 다음날 일주.
- 생시 모름: 정오 기준 년·월주, 시주 None.
- `Manseryeok` 추가 옵션은 기본값에서 기존 결과와 동일해야 함: `term_precision="minute"`, `equation_of_time=False`.
- 절기 계산(Meeus/VSOP87 축약)은 `_of_year_cached` 로 캐시 — 순수 함수 유지.

## 시간대

- 서머타임·UTC+8:30 시기는 백엔드(`app/services.py`)가 `zoneinfo("Asia/Seoul")` 오프셋을 구해 `tz_hours` 로 넘긴다(옵션 `dst_auto`, 기본 켬).
  1908년 이전은 tzdata 상 지방평균시(LMT).

## 분석 모듈 (휴리스틱)

- `twelve_stages.py`, `sinsal.py`, `luck.py`, `yukchin.py` 는 표준 규칙표 — 표 수정 시 출처 확인. 육친은 학파차 있음(화면에 명시).
- 자리별 강약(`slot_power`) = 100 × 왕상휴수사(월지 정기 대비) × 작용 후 잔존율 ("십성이 놓인 자리 · 지지 강약" 카드).

## 12운성 적용법 (사용자 제공 정의 — twelve_stages.py)

| 방법 | 정의 | 함수 / 필드 |
|---|---|---|
| 봉법 | 일간 → 년·월·일·시지. 년지 초년운 · 월지 청년운 · 일지 장년운 · 시지 노년운 | `stage_of(dm, b)` / `branch.stage`, `branch.period` |
| 좌법 | 각 지지의 지장간 글자를 그 지지에 대입 (십성 이름은 일간 기준) | `jwabeop()` / `branch.stage_jwa` |
| 인종법 | 천간에 뜬 글자(일간 제외)를 **일지**에 대입해 그 십성(육친)의 상황을 봄. 천간에 없는 십성 그룹은 있다고 가정하고 일지와 음양을 맞춘 글자를 끌어옴 (일지 음양 = 정기 기준). 가정 글자는 통변하지 않는 학파도 많음 → 옵션 `injong_assume` | `injongbeop()` / `injong`, `injong_branch` |
| 거법 | 각 기둥 천간 → 같은 기둥 지지 (년간→년지 …) | `geobeop()` / `branch.stage_geo` |

- 좌법 정의의 "일간을 기준으로"는 십성 명명 기준으로 해석함. 다른 해석이 필요하면 사용자 확인.
- `CalcOptions.jwabeop` 은 12운성 좌법과 무관한 "같은 기둥 천간·지지 상호 영향(세력 ±10%)" 옵션 (이름은 하위호환 때문에 유지).
- `analysis.py` 의 작용 강도·세력·신강도·격국·용신은 **휴리스틱**. 가중치는 파일 상단 상수에만.
  가중치를 바꾸면 화면 수치가 바뀌므로 변경 이유를 남기고 사용자에게 알린다.

## 알려진 한계

- 절입 ±5분 이내 출생은 KASI 자료와 교차 확인 필요 (API `meta.near_term_warning` 으로 표시 중).
- `korean_lunar_calendar` 지원 범위 밖 음력은 `ValueError` → 422.
- 동지세수, 다른 지장간 배분표는 미구현.

## 코드 규칙

- 표준 라이브러리만 (`korean_lunar_calendar` 는 음력 변환에서 지연 import).
- 웹/HTTP/Pydantic 의존성을 이 패키지에 넣지 않는다.
- `Stem`/`Branch` 는 싱글턴 — `is` 비교 성립.
